# GlobalLove.com

Plataforma global 100% gratuita de namoro e conexões em 92 países, com suporte automático a 8 idiomas, vídeo chamadas, chat multimídia, cálculo de distância, afinidades mútuas e painel administrativo (`/admin`) com métricas reais.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

A pasta final gerada será `dist/` (já configurada com `vercel.json` e `public/_redirects` para Vercel, Netlify e Cloudflare Pages).

## Como publicar grátis a partir do GitHub

1. Crie um repositório em [github.com/new](https://github.com/new) e envie os arquivos deste projeto.
2. Acesse [vercel.com](https://vercel.com) (ou Cloudflare Pages / Netlify), conecte sua conta do GitHub e importe o repositório.
3. Clique em **Deploy** para obter sua URL pública gratuita com HTTPS.
4. Envie a URL publicada e o `sitemap.xml` no [Google Search Console](https://search.google.com/search-console) para indexar no Google.
